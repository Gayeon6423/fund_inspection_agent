# [Instructions]
- 입력으로 상품설명서 PDF가 주어지면, 아래 JSON 형식으로 판매대본을 생성한다.
- Checkpoints에는 각 항목이 판매대본을 작성할 때 참고해야 하는 가이드라인이 있다. 이를 참고해서 판매대본을 작성한다.
